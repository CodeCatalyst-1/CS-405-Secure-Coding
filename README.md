# CS-405-Secure-Coding

CS-405 Secure Coding Portfolio

Ethan Chapman
Southern New Hampshire University

This repository contains all coursework completed for CS-405: Secure Coding. Throughout this course, I explored secure software development practices, risk assessment methodologies, encryption concepts, and real-world security case studies. The purpose of this portfolio is to demonstrate both technical implementation and conceptual understanding of cybersecurity principles and how they apply to modern software development.

The repository is organized into branches by week to clearly demonstrate progression throughout the eight-week course. The main branch contains the complete portfolio with all coursework, while individual weekly branches isolate assignments specific to each module. This structure allows for clear version control, organization, and separation of topics as they were introduced and developed over time.

During this course, I developed skills in identifying software vulnerabilities, applying secure coding best practices, implementing encryption techniques, conducting structured risk assessments, and writing secure exception handling logic. I also gained experience developing organizational security policies and analyzing real-world security breaches to understand how weaknesses in systems can lead to large-scale data exposure.

Key topics covered in this course include the Secure Software Development Lifecycle (SDLC), threat modeling, vulnerability mitigation strategies, cryptography fundamentals, input validation, error handling, and security policy design. Each assignment contributed to building a stronger understanding of how security must be integrated into every phase of development rather than added after an issue is discovered.

The tools and technologies used throughout the course include C++, Java, Python, Git, GitHub, and Microsoft PowerPoint for documentation and presentations. These tools supported both technical implementation and professional communication of security concepts.

The final project focused on developing a structured security policy supported by formal risk assessments and secure coding standards. This project integrated technical analysis, documentation, and mitigation planning to reflect real-world cybersecurity practices and demonstrate the importance of proactive security planning.

Overall, this course strengthened my understanding of secure coding principles and reinforced the importance of designing software systems with security in mind from the beginning. The knowledge and practical experience gained through this coursework provide a strong foundation for future work in cybersecurity and secure software development.
